# The Escape Files — Tankothek

A static visual library for GitHub Pages. No build step or backend required.

## Content

30 archive entries across six topic weeks, imported from the earlier Escape Files website package dated 11 November 2026. Includes the 25 X post links supplied in that archive, official source links, and known Paragraph article links. Files 006–011 additionally include original full text and covers from the user's Week 02 package. Titles 007 and 009 were resolved from those originals. Other covers and missing article links remain explicitly marked pending.

Original editions, editorial summaries, documented information and open questions are distinguished. Published/planned/review statuses reflect the imported archive date, not a live synchronization with X. Official fees and whitelist documentation checked 12 November 2026.

## Features

Search, topic/week/status filters, sort order, local saved files, direct file links such as `#file-007`, modal reading view, six-week index, Knowledge Base and open questions. Responsive layouts and reduced-motion preference support.

The homepage and navigation support ten languages. Archive controls and indexed File text support English and German. Original covers retain their embedded text.

## Hosting

Publish the repository root from the main branch using GitHub Pages. All files, including six original PNG covers, are in the root directory. `.nojekyll` disables Jekyll processing. Expected address after successful deployment: https://tankothek.github.io/the-escape-files/

## Maintenance

Archive content and sources live in data.js. FILES defines the original index, WEEKS the weekly reading paths, SOURCES official references and originalEditions the six full original texts. Each edition has a unique three-digit ID. Add original covers and update the mapping when new originals become available. Review archive statuses against original publications before changing them. Knowledge Base text is in index.html with a source-check date. Never invent missing titles or links.

## Privacy

Saved files stay in browser localStorage on the current device. No analytics, account system or submission forms. Google Fonts provides typography, with system fallbacks. External links use separate tabs.
